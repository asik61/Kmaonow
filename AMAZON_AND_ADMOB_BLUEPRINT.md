## 4. Google AdMob Approval Strategy & Secrets

Jab aapka app Amazon Appstore par live ho jaye, tab AdMob approve karwana bohot aasan ho jata hai!

### Step 1: AdMob Account Setup
1. **[admob.google.com](https://admob.google.com/)** par jayein.
2. Apne Google account se sign in karein.
3. Country: **India**, Currency: **INR (Indian Rupee)** select karein.
4. Account verify karein (Name, Address, Phone number).

### Step 2: Add App to AdMob
1. Left menu me **Apps** -> **Add App** par click karein.
2. Platform: **Android**.
3. Question: *"Is the app listed on a supported app store?"* -> **YES** select karein!
4. Store option me **Amazon Appstore** choose karein.
5. Search bar me apna app name ya Amazon Appstore URL paste karein aur **Add** par click karein.
6. AdMob automatically status **"In Review / Getting Ready"** dikhayega.

### Step 3: High-Earning Ad Units Create Karein
Earning apps me 3 sabse best ad formats hote hain:
1. **Rewarded Video Ad** (Highest Earning - ₹100-₹300 eCPM):

2. **Interstitial Ad** (Full Screen Ad):

3. **Banner Ad**:

## 5. AdMob App-ads.txt Setup (Mandatory)

Google AdMob unauthorized traffic aur fake ads rokne ke liye `app-ads.txt` maangta hai:

1. Humne aapke project me file create kar di hai: `/public/app-ads.txt`
2. Jab aapka AdMob account ban jaye, tab AdMob console me jayein:
   - **Settings** -> **Account Information** -> **Publisher ID** copy karein (Jaise: `pub-1234567890123456`).
3. `public/app-ads.txt` file me `pub-XXXXXXXXXXXXXXXX` ko apne real publisher ID se replace karein:
   ```
   google.com, pub-1234567890123456, DIRECT, f08c47fec0942fa0
   ```
4. Jab aap deploy karenge, toh `https://realmoneyapp.online/app-ads.txt` automatically live ho jayega aur AdMob crawler ise green checkmark de dega!
